## main CI 修复：RC003 钩子产物必须先于 cargo 测试产出（PR #2）

- PR #1（feat/rc003-native-tap-probe）合入 main 后 CI 失败（run 34736626693）。
- 根因：`tauri.conf.json` 的 `bundle.resources` 引用 `../target/rc003-hook/` 下的注入器 exe 与钩子 DLL；`cargo test/check --workspace` 编译 `src-tauri` 时 tauri-build 在**构建脚本阶段**即校验 resources 存在，而 CI 里 "Build RC003 hook native components" 原排在 NSIS 打包前、cargo 测试后，顺序错误。
- 修复（PR #2，分支 fix/ci-rc003-hook-before-cargo，commit 88779ed）：钩子构建步骤前移到 "Test Rust workspace" 之前，旧位置删除。windows-release.yml 无此问题。
- 教训：给 tauri.conf.json 增加 bundle.resources 引用构建产物时，**任何** cargo 命令（含 test/check）只要编译 src-tauri 就会触发 tauri-build 校验——产物必须在所有 cargo 步骤之前生成。
